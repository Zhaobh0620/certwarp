## 3. 折叠指标：证书与四面体代理不一致

同样 12 个终态，原生网格共 6,772,287 个单元：

| 指标 | 结果 |
|---|---|
| 证书（区间 Bernstein，全单元 J 下界） | 全部 > 0，最小下界 1.2e-7–3.9e-6 |
| 官方 foldings、中心差分 det ≤ 0 的比例 | 全部为 0；中心差分 det 的最小值 .015–.035 |
| 24 四面体，比值 ≤ 0 的单元 | 每个终态 123–1613 个，最小比值 −.108 到 −.588 |
| 6 四面体（Kuhn） | 2132–10921 个，最小 −.49 到 −2.42 |
| 5 四面体 | 172–1514 个，最小 −.18 到 −1.03 |
| 对 24 四面体标负的每个单元，在 17³ 网格上直接算三线性 J | 0 个 ≤ 0；这些单元上的最小 J 为 .00078–.0123 |

- **解读**：我们的形变是 Q1（三线性）映射，证书证明的是这个映射在每个单元内处处 J > 0。四面体指标用同样的 8 个角点构造另一个分片线性映射，它在这些单元里出现负体积，而三线性映射本身没有折叠。最后一行的密集采样不调用证书代码，是独立核对。规划 WP-0.3 已指出两者互不蕴含。
- 这些单元都在强压缩区：被标负的单元里，单元内最小三线性 J 的中位数在各终态为 .031–.041。例如 X3 开发对终态里 24 四面体比值最低的单元（−.108），24 个比值的平均是 .0975，等于单元平均 J，单元内三线性 J 在 .0126–.26 之间。
- 所以 24 四面体指标只能叫"P1（Heldmann-24）代理折叠指标"，不能代替证书，也不能说明我们的映射有折叠。
- **对论文口径的影响（待用户决定）**：长期目标写的是"以单元级（四面体）检查零折叠，由证书保证"。按现在的模型，证书保证的是三线性映射零折叠，四面体检查并不为零。可选做法：
  1. 论文按 Q1 映射定义折叠：主张由证书保证，同时并列报告官方指标与四面体代理，并说明差异来源；
  2. 在模型里加入四面体条件，例如对 24 个四面体也做 barrier 和认证。这会改变目标函数和接受规则，必须先经用户确认。
