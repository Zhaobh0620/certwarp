## 0. 要点

1. **数据**：LPBA40 S03–S36，34 人。
   - 设计：17 个顺序不相交对 S03←S04、S05←S06、…、S35←S36。前者 fixed，与论文一 stage_LPBA40_v1 的约定相同。
   - 每人只在一对里，所以按对重抽就是按受试者分块重抽（第 3 节）。
   - S01–S02 只作可行性对（两个方向），不读真值（第 7 节）。S37–S40 不碰。
2. **预处理**：用 delineation 空间原样，参数都在读任何真值之前定死（第 2 节）。
   - 照论文一的读法，做 RAS 存储重排，不重采样。
   - 加一步按解剖的左右翻转：数组第 2 轴翻转，即论文一 BL2 Amendment 7 选项 A 的 P。
   - **强度改为 v / p99.5_脑内(v) × c，不截断**。c 是开发集 L2R 验证 20 人 stage 影像脑内 p99.5 的中位数，由一项工具在任何 LPBA 运行之前算出并提交（第 2.2 节 P5）。
   - 所有臂用同一份准备好的影像。不做仿射归一化，也不做直方图匹配。
3. **臂**：共 6 臂：方法 Hx24-RF05-F1200-v4（冻结，settings_sha256 414eccd3…）、配置 C、ants_s、fireants_greedy、fireants_syn、convexadam_v4seg。
   - 设置照留出集的冻结文件，不为 LPBA40 调任何参数。
   - 恒等场作参照，不检验（第 4 节）。PQ 不在 LPBA40 上跑。
4. **终点**：
   - 主终点 **lpba54**：56 个 LPBA40 标签去掉 181 小脑、182 脑干，用本仓库的 macro Dice 口径（两边都没有就跳过，只在一边就记 0）。
   - **lpba56** 同一口径，作关键次要终点，同判法、单独一族 Holm。两种平均都报（CLAUDE.md）。
   - 理由：delineation 影像在小脑上全是 0、脑干大部分是 0（第 5 节）。
5. **判法**（照抄留出集，种子另定，另加 t 门）：
   - Δ = 方法 − 对手，取 17 对的均值。
   - 三类单侧检验：优于（H0: Δ ≤ +.005）、劣于（H0: Δ ≥ −.005）、相当（TOST ±.01）。
   - 每一类各算两个 p 值：
     - 按对重抽的自助 p 值：10000 次，`numpy.random.default_rng(20261119)`，加 1 修正；
     - 配对 t 检验的 p 值：df 16。
   - **取两者的较大者**，再在 m = 5 个对手上做 Holm（单侧 .025）。同一 Holm 步两种检验都拒才算拒。
   - 判定次序：优于 → 劣于 → 相当 → 无法下结论。
   - "优于"另过 SDlogJ 护栏：官方 SDlogJ 差的自助 95% 上界与 t 上界，取较大者，要 < +.02（完整对）。
   - 缺输出按恒等场意向处理（第 6 节）。
6. **运行**（次序照第 8.1 节）：
   - 本预登记定稿（本版）→ 名单与臂表提交 → 合同修订 → c 的工具复核并入，c 与 W_dev 算出并提交 → T24 薄包装与其余工具并入、代码钉值 → 开发集逐位对照 (b)、(c) → 可行性对（S01–S02，含 (a) 与 WM 比值；不读真值，只查工具错误）→ 钉住提交 P_L → 与 T24 运行排好先后。(d) 是合成测试，随工具一起过。
   - 正式运行按臂跑，每个 (臂, 对) 只跑一次。
   - 全部输出与清单提交进 git 之后，唯一的评测入口读一次真值。
   - 之后判定代码 → 结果文档 → 独立复核（第 7、8 节）。
   - 〔估算〕正式运行机器时间约 4–6 h，留存约 30 GB，全放 /home（第 11 节）。
7. **事先写明的风险**（任务书）：
   - 方法的 T88 只看 35 个 argmax 通道（OASIS 协议，皮层是一个标签），脑回级的对齐只靠皮层带的形状；

**delineation 空间是什么**（Shattuck 等 2008 §2.2、§2.4，起草员读全文转述）：
- **刚体，不缩放**：每人的 MRI 用手点的标志点刚体对到 MNI-305 平均脑。原文："six parameter linear transformation (three-translation, three-rotation rigid-body, no rescaling)"，"to preserve the native dimensions of the subject"。
- **偏场**：用 nu_correct 校正过。
- **没有小脑、脑干**：去颅骨时"the cerebellum and brainstem were also removed manually to produce a cerebrum mask"。所以 delineation 影像在小脑上是 0、脑干大部分是 0。这与论文一的观察一致：BL2LPBA README §6 在 S01 上量到小脑标签 0% 非零、脑干 16% 非零。
- **56 个结构**："50 cortical structures, 4 subcortical areas, the brainstem, and the cerebellum"。
- **更正**：论文一设计草稿 D1（archive/seq_vp_3d/docs/design_draft_D1_LPBA40.md §1，sha256 a5a7c2b8…）写"delineation 空间已做过仿射对齐"。照原文，是刚体、不缩放。

### 2.2 LPBA40 的准备步骤（参数在读任何真值之前定死）

**c 的定义**（裁决 B1，总负责人定；c 由第 12 节第 3 项的工具算，本预登记不给数）：
- **c** = 开发集 L2R 验证 20 人（data/three_d/stage_L2R_val_v1 的 20 名受试者）stage 影像的脑内 99.5 百分位的中位数。
  - 每人的值是 `np.percentile(v[v > 0], 99.5)`（linear），v 是该人在 stage pair.npz 里的 fixed 或 moving 数组。只读这两个成员，不读任何 seg 键。
  - 一人出现在两对里时，两处必须逐位相同；不同就停下，算工具或数据错误（复核次要 9）。

- **同一工具还算 WM 参照值 W_dev**：每人的 stage 影像在 Atropos WM 后验 > .5 的体素上取均值，W_dev 是这 20 个均值的中位数。Atropos 后验用开发集上方法已在用的那一份组织层（HE 开发集的 atropos_root；路径由工具写进记录）〔未核：具体路径〕。W_dev 供第 7 节的描述量用。
- **提交**：逐人值、c、W_dev（十进制与 float.hex 都写），读过文件的 sha256，代码提交号。这些要在任何 LPBA 运行之前提交进 git，sha256 写进 decision_log；之后数据准备工具钉住这份记录的 sha256。这一步不读任何真值。

数据准备进程**不读任何标签文件**（不打开、不算 sha256），只读 34 + 2 人的 delineation/image.nii.gz。

- **左右核对（只记录）**（复核 I3 (d)）：每人记录 27 对左右标签在数组第 2 轴上的质心差的符号，应与 OASIS 一致：左结构在低下标一侧。不改任何东西，只进评测记录与结果文档。

### 2.3 左右翻转（裁决 (4)：在 stage 一级做）

理由：
1. 分割器只在解剖方向正确的 OASIS 上训过，而左右是分开的标签（seg35 的 1–19 是 Left-*，20–35 是 Right-*）。不翻转时它看到的是镜像脑〔推断：脑的对称性高，影响多半小，但不是零；论文一 BL2LPBA README §10 第 1 条同样判断〕。
2. 在 stage 一级做，所有臂看到同一份影像（任务书要求），各臂的输出、评测都在这一份存储上。
3. 翻转是数组下标的置换，不插值；影像与标签做同一个置换。
4. 论文一对学习型方法用的就是这个 P（BZ 2026-10-22 选 A）。

**依据的局限**：
- 左右是论文一在 S01、S02 的标签上定的（BL2LPBA README §3）。
- S03–S36 的头信息与 S01、S02 完全相同（第 1.1 节，36 个头逐字段一样），都出自同一个 LONI 分发包〔推断：存储约定相同〕。

### 2.4 不做的

- **不重采样、不补零、不裁剪到 OASIS 的 160 × 192 × 224**：各部件都接受任意形状（第 2.1 节）。
- **不做 N4 或其他偏场校正**：原文已用 nu_correct 校正过（§2.2）。

### 2.5 仿射归一化（裁决 (3)：不做）

- **差别**：OASIS 的输入经过仿射对齐，头的大小被归一化；LPBA40 delineation 空间只有刚体，保留原大小（第 1.1 节）。所以：
  - 分割器会遇到尺度上的域偏移（训练增强没有空间缩放，第 2.1 节）；
  - 对内两人的整体大小差要由形变来吸收。方法、配置 C、FireANTs、ConvexAdam 都没有仿射一级，而 **ants_s 有自己的刚体 + 仿射一级**（antsRegistrationSyN.sh -t s），这一点对 ants_s 有利〔推断〕。
- **不做的理由**（裁决 (3)、I5）：
  - 不加工具与参数：参照模板、配准工具与参数、失败处理，都是新的选择；
  - 标签不插值，评测就在原 delineation 网格上；
  - 冻结配置不调：不为 LPBA40 引入任何会影响各臂的新步骤。
- **与文献不同**：LPBA40 的配准文献常见的做法是先把影像配到 MNI152。例如 Li 与 Fan 2018 用 delineation 空间的 LPBA40，再配到 MNI152（2 × 2 × 2 mm³）并做直方图匹配（PMC6070305，起草员读全文核过）。本文不这样做，所以本文的数不能与这类文献直接比（第 13 节）。

**为什么另加配对 t 的门**（复核 I1；裁决 I1）：

- 16 个自由度时，t 的分位数是 z 的 1.13 倍（.995 处，2.921 对 2.576）和 1.08 倍（.975 处，2.120 对 1.960）。
- 所以判定要求两种检验都拒（第 6.4 节），下面的门槛由 t 决定。

## 5. 终点

**评测入口**：所有臂、所有对经同一个入口。指标只由评测代码从 disp.npz 算（键 d，形状 (3, nz, ny, nx)，体素单位，拉回方向）；方法自报的数不进表（CLAUDE.md 评测约定）。指标函数照 bayesreg.eval.metrics（sha256 36828cfb…）已有的 LPBA40 方案 `lpba40_scheme(ids)`（metrics.py:67–74），它给出两个 macro 集：

- lpba54：去掉 181、182（常量 LPBA40_EXCLUDED_54，:46）。

脑掩膜的键是 brain。

### 5.1 主终点：lpba54（裁决 (1)）

- **定义**：jd_curl.three_d.nifti.dice_labels 在 54 个 ID 上的 macro Dice，即 metrics 文件头"seg35, seg4"一条用的同一函数。**一个标签在 fixed 与拉回的 moving 里都没有时跳过；只在其中一边出现时记 0**。这与留出集 seg35 的缺失规则相同（任务书第 5 条）。
- **54 个 ID**：21–34、41–50、61–68、81–92、101、102、121、122、161–166，共 54 个（出处 notes/label_id_map.md）。56 个 ID 再加 181、182。ID 表写成常量钉进评测入口，**不从标签体素里读**（论文一脚本是从体素里取的）。
- **为什么 54 为主**：
  1. **影像里没有这两块**：delineation 影像在小脑上全是 0、脑干大部分是 0。原文 Shattuck 等 2008 §2.2："the cerebellum and brainstem were also removed manually to produce a cerebrum mask"；BL2LPBA README §6 在 S01 上量到小脑 0% 非零、脑干 16% 非零。这两块里任何方法都看不到影像，Dice 量的是正则化怎么带着标签走，不是对齐。
  2. **论文一的惯例**：H2 的标签修订（archive/seq_vp_3d/results/verification/3d_stage_HOLDOUT_v1/plan/amendment_20261022_H2_labels.md，sha256 49d82135…）。BZ 2026-10-22 约 10:48 AM 选"54 个标签为主"：主指标是除 181、182 之外 54 个标签的平均，56 个的平均也报。
  3. **文献**：Li H, Fan Y. Non-Rigid Image Registration Using Self-Supervised Fully Convolutional Networks Without Training Data. Proc IEEE ISBI 2018:1075–1078. doi:10.1109/ISBI.2018.8363757（PMC6070305）。
     - 他们的标签"excluding cerebellum and brainstem"，Dice 在 54 个 ROI 上算。
     - 他们的预处理与本文不同：先配到 MNI152（2 mm）并做直方图匹配（第 2.5 节）。
     - 原文没有写排除的理由。
     - 54 的惯例还有哪些出处：**未找到更多出处**（只核了这一篇）。Shattuck 等 2008 本身是 56 个结构。

### 5.2 关键次要：lpba56

- 同一函数、56 个 ID、同一判法，单独一族 Holm（族 L2），结论单列为"关键次要"。
- 它对应留出集里 seg4 的位置（留出集 P1）。LPBA40 没有 seg4 那样的大结构集，所以用 56 个标签的平均。
- 它与 lpba54 高度相关〔推断〕，两族的结论多半相同。单列是为了满足"54 与 56 两种平均都报"，并给出各自的判定。

## 6. 假设与判法（照抄留出集，逐条写出处；另加配对 t 的门）

### 6.1 量

- 第 i 对（i = 1..17，按 test_pairs.tsv 去掉表头后的行序）、臂 a 的 lpba54 记 S_{a,i}，lpba56 记 G_{a,i}。
- 对比较对象 k：Δ_{k,i} = S_{方法,i} − S_{k,i}（lpba56 同理），Δ̄_k = (1/17) Σ_i Δ_{k,i}。正值表示方法好。
- s_k 是 Δ_{k,i} 的样本标准差（ddof 1），SE_k = s_k / √17。
- 统计量取均值。另报中位数、方法胜的对数、双侧 Wilcoxon 符号秩 p 值，都只描述（留出集第 4.1 节）。

### 6.2 主假设

> **H_L**：在 LPBA40 S03–S36 的 17 对上，方法 Hx24-RF05-F1200-v4（含退路的方法级输出）的 lpba54 均值，比主族的每个比较对象都高出 ROPE 上沿（Δ̄_k > +.005）。主族是：配置 C、ANTs SyN `-t s`、FireANTs Greedy、FireANTs SyN、ConvexAdam-v4seg。

- 每个比较对象各得一个判定，逐个报告，不合成"对全部对手都优于"一句结论（留出集第 4.2 节）。
- **"劣于"与"优于"同样是确认性的判定**（第 6.4 节）。结果可能变差，所以劣于的写法事先写清。

### 6.3 重抽（照留出集第 4.3 节；种子另定）

- **抽样**：`rng = numpy.random.default_rng(20261119)`，每次 `idx = rng.integers(0, 17, 17)`，共 B = 10000 次；第 b 次 Δ̄*_{k,b} = mean(Δ_{k,idx})。
- **种子 20261119**（裁决 (11)）：本预登记的日期，在任何 LPBA40 运行之前定死。它与留出集的 20261107 不同，只因为这是另一份预登记。
- **共用一串**：所有比较对象、lpba54 与 lpba56、各描述终点、护栏都用同一串 idx。
- **区间**：
  - 自助区间：numpy.percentile 默认 method（'linear'）的 2.5、97.5 百分位，不调整；
  - t 区间：Δ̄ ± t_{.975,16}·SE；
  - 两种都报。

### 6.4 判定与 Holm（照留出集第 4.4 节与修订 2 第 3 条；加 t 门，裁决 I1）

对每个比较对象 k，每一类算两个单侧 p 值。

**自助 p 值**（照抄留出集，加 1 修正）：
- p^{sup,B}_k = (1 + #{b : Δ̄*_{k,b} ≤ +.005}) / (B + 1)：检验"优于"，H0: Δ ≤ +.005；
- p^{inf,B}_k = (1 + #{b : Δ̄*_{k,b} ≥ −.005}) / (B + 1)：检验"劣于"，H0: Δ ≥ −.005；
- p^{eq,B}_k = max(p^{lo,B}_k, p^{hi,B}_k)，检验"相当"（TOST，±.01，边界算进计数）：
  - p^{lo,B}_k = (1 + #{Δ̄* ≤ −.01}) / (B + 1)；
  - p^{hi,B}_k = (1 + #{Δ̄* ≥ +.01}) / (B + 1)。

**配对 t 的 p 值**（df = 16；F 是 t_{16} 的分布函数，scipy.stats.t.cdf）：
- p^{sup,t}_k = 1 − F((Δ̄_k − .005) / SE_k)；
- p^{inf,t}_k = F((Δ̄_k + .005) / SE_k)；
- p^{eq,t}_k = max(p^{lo,t}_k, p^{hi,t}_k)，其中 p^{lo,t}_k = 1 − F((Δ̄_k + .01) / SE_k)，p^{hi,t}_k = F((Δ̄_k − .01) / SE_k)；
- SE_k = 0（所有差相等）时：分子严格落在备择一侧取 p = 0，否则取 p = 1。

**合成**：每一类取 p^c_k = max(p^B_k, p^t_k)。两种之中只要有一个是有效的单侧 p 值，它们的较大者就是有效的：P(max ≤ α) ≤ P(有效的那个 ≤ α) ≤ α（复核次要 4）。

**置 1 的情形**（复核次要 3）：某个 k 在某一族里"不判"（停臂，包括导出约定可疑到第 2 对；或判定代码认定这一臂缺记录）时，它在这一族的 p^B 与 p^t 都置 1，留在族里，m 不变。

**Holm（步降）**：
- 三类各自在主族 m = 5 个比较对象上，对 p^c 做 Holm，单侧 α = .025。
- 调整后 p̃_(j) = max_{i ≤ j} min(1, (m − i + 1)·p^c_(i))；p̃_(j) ≤ .025 即拒绝；遇到第一个不过就停。
- 这等于"同一 Holm 步两种检验都拒才算拒"：第 j 步要 p^B 与 p^t 都 ≤ .025/(m − j + 1)。
- 次序由 p^c 定；p^c 相等时按主族次序：configc、ants_s、fireants_greedy、fireants_syn、convexadam_v4seg（复核次要 2）。
- Holm 的次序与各步只由意向处理（主分析）的 p^c 决定。

**判定**：
- 按 **优于 → 劣于 → 相当 → 无法下结论** 的次序，取第一个被拒的类（留出集修订 2 第 3 条；holdout_decide.py 的 rejected_classes 次序）。
- 被拒的类可以重叠：照次序取一类，都记进记录。
- 降级（第 6.5、6.6 节）之后不回头改判"相当"。

**族**：

- **L2**：lpba56，同样 5 个对手，单独一族，结论单列为"关键次要"；

- 族与族之间不再校正，主结论只来自 L1。
- **LPBA40 的族与 OASIS 留出集的 F1–F4 互不校正、不合并**：两份预登记各自成立，结论分开报告（第 6.9 节）。

## 13. 它证伪不了什么

1. **一次抽样、17 对**：
   - 每对每臂只跑一次；方法的修复在 GPU 上不逐位可复现；ANTs 不固定种子。
   - 只用自助法时，17 对的实际错误率偏高：复核员估第 1 步名义 .005、实际约 .012，第 5 步名义 .025、实际约 .038。加了配对 t 的门之后，在差近似正态时回到名义水平；差明显偏离正态时，t 也只是近似（第 6.4 节）。
   - "相当"与护栏都难成立；"无法下结论"不等于"一样好"。
2. **整条流程的比较**：对配置 C 的差同时含分割器通道、T88、修复与退路，分不开。
3. **调参不对等**：方法的超参数在 OASIS 开发集上选过，外部基线零次调参；在 LPBA40 上谁都没调。
4. **预处理对各臂不中性**：
   - delineation 空间只有刚体对齐（第 2.5 节）。ants_s 有自己的仿射一级，其余臂没有；分割器训练时见的是仿射归一后的脑。若方法不如 ants_s，分不开"方法差"与"缺仿射"〔推断〕。
   - LPBA40 的配准文献常见的做法是先配到 MNI152（例如 Li 与 Fan 2018：MNI152 2 mm 加直方图匹配）。本文不这样做，数不能与这类文献直接比。
5. **强度尺度只对齐了一个分位**（裁决 B1）：
   - P5 让脑内 p99.5 等于开发集 OASIS 的中位数 c。但两个数据集的扫描与序列不同〔细节未核〕，偏场校正与归一化也不同（LPBA40 用 nu_correct，OASIS 的 aligned_norm 来自 FreeSurfer 的流程〔未核细节〕），直方图的形状不同。
   - 配置 C 与 T88 的数据项尺度只在这个分位上与 OASIS 一致。WM 比值的描述量（第 7.2 节）只挡住粗的不一致。
   - 不做直方图匹配。
6. **分割器的域偏移**：跨站点、跨扫描、没有小脑。对齐 QC 不过的对走退路一，方法在那些对上就是配置 C。
