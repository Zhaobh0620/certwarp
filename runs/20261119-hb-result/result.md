### 2.1 证书与折叠计数怎么读

- **两种证书**：
  - **方法的判据**是配置 C 的证书（PrescreenCertificateConfig，δ 0，max_depth 48，max_boxes 255，tile 65536，CPU FP64，full 模式：含六面为零与采样域）。第 4 步决定证书 50/50 通过，第 5 步复核证书 50/50 与之逐项一致（decision_log 第 459、461 行）；评测入口对 output/final.npz 再算一次（D112 (a)），50/50 通过，n_infeasible、n_uncertain 都是 0，最小下界 1.94e-09（decision.json certificates.method.decision_configuration）。

### 7.4 它证伪不了什么（照预登记第 7 节与修订 2 第 1 条改读）

- 一次抽样：每对每臂只跑一次；方法的修复在 GPU 上不逐位可复现；方法（v4，C 关）在 HE 上的重复性只有冒烟里的一个点。
- 对配置 C 的差同时含分割器通道、T88、修复与退路，分不开；留出集上没有 C 的消融（D82 = II-a）。
- 调参不对等："优于"只能说"优于这些冻结配置下的基线"。
- 只有 OASIS（同一来源、同一预处理）；跨数据集的泛化没有检验（第二测试集 LPBA40 由总负责人另定，decision_log 第 513 行，尚未开始）。
- Dice 量的是与 FreeSurfer 标签的一致；方法的分割器就是学这些标签的；ConvexAdam-v4seg 用同一个分割器，才把"配准好"与"分割器好"分开一部分。
- 只看均值、只看 seg35 / seg4；分结构的 Dice 只在附录 A 描述。
- 时间不对等也不同时；没有计时金丝雀。
- 方法输出全单元 J > 0 是认证过的，它说明的是可逆性（依据论文一的命题 P3，docs/reference/paper1_01_理论.md:177：u 在边界为零、full 模式证书通过，则映射是闭区域上的双 Lipschitz 同胚；本仓库把它作为外部定理引用），不是精度；外部臂不满足六面为零（2.1），它们的折叠与证书只描述。
- 留出集不检验后验与形变不确定度；PQ 检验的是误差定位能力（F4）。
- 上游（HI 推断、Atropos）在留出集上能否逐位重现，没有量。
- 主终点是本仓库 seg35，与 Learn2Reg 官方 Dice 不是同一个函数，不与文献数字比。

### 修订 4.2 量的是什么

- **24 剖分**（folding_metrics.py 文档串："FAIR/Heldmann"）：每个 Q1 单元取 8 个角点的像 x + u(x)、6 个面心（该面四个角点之像的平均）与单元中心（八个角点之像的平均）；每个面的每条边，连同该面面心与单元中心，组成一个四面体，6 个面 × 4 条边 = 24 个。**比值** = 变形后四面体的有符号体积 / 恒等时的体积（边向量行列式之比，恒等时为 1）。6 剖分（Kuhn，主对角线 1→8）与 5 剖分只用 8 个角点，是 tet_ratio_summary 缺省一并算的。
- **每对每种剖分记**：min ratio（全网格所有四面体比值的最小值）；有比值 ≤ 0 的单元数（一个单元里任一四面体比值 ≤ 0 就计）；比值 ≤ 0 的四面体数。"单元比例" = 前者 / 全网格单元数。**全网格**，不分脑内外：补算不读真值，没有脑掩膜（第 2.1 节 BL1 细目里"脑内 / 背景"的分法用的是真值脑掩膜，这里没有）。
- 每个场 191 × 223 × 159 = 6,772,287 个单元（节点 192 × 224 × 160 = 6,881,280，第 2.1 节），所以单元比例 1e-4 约合每对 677 个单元。
- **它量的是另一个映射**。24 个直边四面体把上面 15 个点（8 角点、6 面心、1 中心）的像连起来，构成一个分片线性映射。这个映射在这 15 个点上与三线性插值 Φ_u 相同（面心与中心处三线性插值的值正是对应角点之像的平均），其余各点一般不同。证书认证的是 Φ_u：每个闭单元上 J > 0。一个四面体的比值 ≤ 0，说的是这个分片线性映射在那个四面体上反向，并不给出 Φ_u 在那里的 J。反过来，Φ_u 上有 J ≤ 0 的点，也不一定使哪个四面体的比值 ≤ 0。两者互不蕴含：
  - 合同 C24.12-1；
  - folding_metrics.py 文档串（"Neither direction implies the certificate's whole-cell J > 0"）；
  - 论文一 [P1, Remark 4.8]（arXiv 2611.06954 v1）。照 docs/bayesreg/notes/论文一定理核对_arXiv_20261119.md 的对照，Remark 4.8 把有限差分 J、24 四面体解释与 L2R 折叠数列为证书之外的对象。该核对稿本身未经独立复核，本修订的起草员没有读 Remark 4.8 原文；
  - 稿件规则 docs/manuscript/claims.md W23 (2)。
- folding_metrics.py 文档串另记：对三线性映射，一个单元 24 个比值的平均等于该单元上 J 的平均（测试核过）。所以单个四面体比值 ≤ 0 时，Φ_u 在该单元上的平均 J 仍可以为正。
- **本文里四个与"折叠"有关的量各是各的对象**，分别报告（W23 (2)），不互相印证，也不互相否定：
